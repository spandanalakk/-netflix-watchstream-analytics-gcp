# 5️⃣ Visualization in Looker Studio

Create a dashboard to visualize churn and engagement metrics.

## ⚙️ Steps
1. Connect to BigQuery (`gold.predictions_user_churn`).
2. Add charts:
   - Scorecard (Avg churn probability)
   - Geo chart (Region)
   - Bar (Device)
   - Scatter (Sessions vs Churn)
3. Add filters for Region, Device, A/B Bucket.

## ✅ Output
Interactive dashboard updating from BigQuery.
